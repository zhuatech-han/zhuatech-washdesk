照片在数据库，不信任文件名、MIME或路径；检查签名、实际解码、尺寸、字节数和角色，下载每次鉴权并no-store。最大2MiB、4096px边长／1200万像素、默认3张最多5张。解码不提供杀毒／内容审核／恶意图片沙箱；图片解码器与运行时须维护安全更新。数据库和备份有客户资料与散列，不入Git；CLI日志不要公开真实数据。

仅允许浏览器同源API，Nginx禁框架嵌入、nosniff、CSP、no-referrer；HTTPS后启用Secure cookie。内置MySQL网络sslMode=trust只供隔离容器网络；外部数据库verify-full并核对CA。前后端非root，后端镜像含Maven工具链（为可重复学习构建）；生产瘦运行时和供应链扫描由交付方进一步验证。
