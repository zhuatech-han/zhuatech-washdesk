# WashDesk 业务规则
知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2

本系统供洗衣／干洗门店逐件追踪顾客衣物，单一经营主体、多个门店的数据范围。不同于酒店布草批次系统。初始库没有顾客、收费或衣物；经营者维护服务价目和挂架。

每个订单固定一个客户、门店、币种、结算方式和取衣日期。每件衣物冻结服务名称和价格，保存物品描述、外观情况、顾客确认备注及独立编号。接收→加工→待挂架→已挂架→已取走；加工或挂架前质检可退回加工并说明返洗理由。取走不可再改为加工。

零售订单在取衣前须核实足额收款；允许预收和分次收款，不允许超收。企业月结客户明确设置授信额度，所有未结清的有效企业订单累计不得超过额度。企业订单全部取走后，可将同门店、同币种、同客户、指定月份的未开票订单形成月结单；订单应收转入月结单但不重复产生应收。月结支付只登记在月结单上；未开单企业订单不直接收款。

可以先取五件中的三件；每一件必须扫描或输入当前编号核对、已挂架且不重复；取衣记录含实际接收人和交接人、时间。占用挂架的衣物取走／返洗后释放挂架容量。挂架减少容量不能低于占用数。处理中的衣物、已有取衣／月结记录的订单不得取消；取消仅在全部衣物仍为待加工时进行，保留原因，预收退款按原收款余额登记，不删除历史。

所有写入使用事务、统一配置行锁和显式版本校验。关键命令UUID绑定账号与完整载荷，在同一事务写入结果，防止重复收费或取衣。权限每次请求读取实时账号／角色；客户账号只读绑定自己的订单及月结单，未绑定者无业务资料。账号与门店停用、重置密码撤销旧会话。外观照片经鉴权访问，数据库内持久化，小型部署限定最多5张／件，每张2MiB，JPEG／PNG签名及尺寸验证。

基础版不接支付网关、短信、公众号、传送线或机器；收款为人工核实记录，不声称自动到账。扫码指键盘式扫描枪输入／手输编号；不声称摄像头扫码或实体打印机已验证。浏览器打印交接收据和衣物标签。中文、英文界面保留经营者输入的原始业务名称。规模上限和部署限制见 README。
